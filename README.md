# portfolioanalysis
I built a reporting model for a 7-fund multi-asset portfolio against a 60/40 benchmark, using five years of total-return data sourced via R, and calculating returns, volatility, Sharpe ratio, tracking error and maximum drawdown.

The purpose of this project is to analyse the monthly performance and report the risk for a model multi-asset portfolio against a 60/40 benchmark.

The data is adjusted close prices for VTI, VXUS, VNQ, BND, BNDX, SHV and VT, Sep 2021 to Sep 2026, downloaded via R (quantmod) from Yahoo Finance.
